# 현재 상태·조치 계획

기준일: 2026-08-10 (Asia/Seoul)

## 현재 판정

센터 기반 상거래 개편의 핵심 코드·DB·권한·원장·결제·물류·취소·상품·알림·UX·정산·스토리지 변경은 현재 브랜치에 반영되어 있다. 다만 목표 파일의 완료 조건인 “모든 단계 완료 후 배포”는 아직 충족하지 않았다. 아래 검증은 현재 기준선이며, 잔여 계획과 최종 배포 게이트를 통과해야 목표가 완료된다.

- 전체 core test: 335개 중 329개 통과, 6개 스킵, 실패 0
- ESLint·TypeScript·production build 통과
- Supabase migration parity: 157개 일치
- 최신 운영 BUILD_ID는 현재 배포 커밋과 일치하지만, 이는 잔여 작업 완료를 의미하지 않는다
- 공개 약관·개인정보 페이지 200, 비인증 cron API 401
- PortOne·중앙 물류는 실행 경로가 폐기되고 역사 읽기만 보존
- 수동 계좌이체, 매장 범위, CAS·멱등·append-only 원장 계약 유지

실제 운영 역할별 QA와 법률 검토는 사용자 결정에 따라 별도 후속 범위다. 운영 데이터에 대한 결제·환불·배송 성공 mutation은 보호를 위해 실행하지 않았다. 따라서 현재 상태는 “배포 완료”가 아니라 “기준선 검증 완료·잔여 작업 진행 전”이다.

## 최근 반영된 조치

- 소유자 메뉴의 404 `사이트·로그` 링크 제거
- 소유자 결제 합계의 전체 페이지 집계
- 소유자 회원 목록 100건 단위 페이지네이션
- 소유자 플랫폼 중복 GET 공유 캐시
- 계좌 원문 열람을 인페이지 표시·즉시 숨기기로 통일
- 운영자 죽은 내비·잘못된 출고 링크 제거
- 운영자 배송 요청 전체 count RPC 추가 및 운영 DB 적용
- 직원 출고·채팅·택배 API의 직원 역할 접근 회복
- 직원 출고 화면 `직원센터` 라벨 추가
- 계정 찜 개수의 전체 ID 기준 표시

## 조치가 필요한 순서

### 1단계 — 계정·홈 P2 기능 정확성

- 찜한 종료·판매완료 상품을 안전하게 복원할 조회 계약 검토
- 홈 경매 레일에서 active 상태만 노출하고 데스크톱·모바일 개수를 통일
- 시드 RNG 주입으로 경매 후보 셔플 테스트의 비결정성 제거

완료 기준: 계정 찜 수·목록, 홈 경매 상태·라벨·노출 수가 서버 상태와 일치하고 관련 테스트가 결정적이어야 한다.

### 2단계 — 남은 관리자 UX 정리

- 운영자 `매출·정산` 대분류를 실제 revenue 화면과 연결할지 UI·테스트 계약을 함께 결정
- `OperatorOrdersConsole`, `OperatorPaymentsConsole`, `OperatorMembersConsole`를 참조 테스트 이전 후 삭제하거나 명시적 호환 자산으로 분류
- 소유자 보안 API 4개를 호출 로그와 복구 계획 확인 후 폐기 여부 결정

완료 기준: 죽은 라우트·컴포넌트·문서가 없고, 남기는 호환 자산에는 명시적 이유와 테스트가 있어야 한다.

### 3단계 — 공통 구조 개선

- 데스크톱 배송지 전용 진입점과 간편모드 닉네임 설정 노출 보완
- Owner·Operator·Employee 세션 취득 패턴을 공통 hook으로 단계적 통일
- 대형 `AccountDashboard` 뷰를 기능별 컴포넌트로 분리
- 직원 `center` 호환 redirect는 테스트와 함께 폐기 여부 결정

완료 기준: PC·모바일 기능 parity, 인증 경계 유지, 단위별 회귀 테스트 확보.

### 4단계 — 외부 검증(선택된 후속 범위)

- 인증된 운영자·직원·밴드회원 계정의 실제 도메인 QA
- 운영 결제·환불·배송 mutation은 격리 테스트 데이터에서만 수행
- 정책 문서는 사용자 판단에 따라 별도 검토·공개 여부 결정

### 최종 완료 게이트 — 배포

- 1~3단계의 완료 기준과 선택된 외부 검증을 통과한다.
- 변경 내용을 커밋하고 배포 전 read-only preflight를 다시 수행한다.
- 배포 후 실제 도메인 smoke test와 롤백 확인을 수행한다.
- 위 항목까지 끝난 시점에만 센터 개편 목표를 완료로 표시한다.
